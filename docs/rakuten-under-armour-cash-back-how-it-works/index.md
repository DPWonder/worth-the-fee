# Rakuten Under Armour cash back: does it work, and what is excluded?

Source: https://itsworththefee.com/rakuten-under-armour-cash-back-how-it-works/
Facts checked: 2026-11-25
Publisher: Worth the Fee (independent; some pages end with a disclosed referral link)

Yes. On November 25, 2026, Rakuten's Under Armour page showed 10% cash back, raised from a base of 2%. The biggest exclusion is coupon codes: an order using any code not listed on Rakuten earns nothing, and gift cards and orders shipped outside the United States are excluded too.

This page is information, not financial advice. Rates change daily, so check the store page on Rakuten on the day you buy. For this morning's headline rate at other stores, see [Rakuten rates today, by store](/rakuten-cash-back-rates-today-by-store/).

## The rate seen on November 25, 2026

| Item | What the page showed |
|---|---|
| Headline rate | 10% |
| Rakuten's "was" label | 2% |
| Category table | None; one rate for the store |
| Average earned per shopper | $23.53, as of the end of 2025 |

A "was" label appears when a rate has been raised above the store's base rate. The page does not say how long 10% lasts, and it does not say over what period the average was measured.

## What is excluded

Rakuten's terms for Under Armour list these as earning nothing:

- Gift cards
- Employee or athlete orders
- Orders using any coupon or promotional code not listed on Rakuten
- Orders the store deems to be for reselling

A special term adds that cash back is only available on orders shipped to the United States.

## Coupon codes and status discounts

Many store pages say an outside code "may void" cash back. Here the outside code is on the exclusions list itself. On November 25, 2026, Rakuten's page listed several codes, including one for an extra 10% off an order.

The page also describes discounts that do not come from Rakuten: 15% off a first order for signing up for the store's emails, a student discount through UNiDAYS, and a discount through ID.me for military, first responders and teachers. Whether these count as codes "not listed on Rakuten" is not confirmed. Under the terms as written, a code from the store's email would not be on Rakuten's list.

## What earns and what does not

| Purchase | Earns? |
|---|---|
| Clothing or shoes, shipped to a US address, no outside code | Yes, 10% that day |
| Same order with a code listed on Rakuten | Yes |
| Same order with a code from elsewhere | No |
| Gift card | No |
| Order shipped outside the United States | No |
| Order judged to be for resale | No |

Prices shown on Rakuten's page that day put this in dollars: the UA Rival Fleece Men's Pants at $60.00 would earn $6.00 at 10%, or $1.20 at the 2% base. Rakuten's general help page says taxes and shipping are never eligible.

## Rewards points, outlet, app and stores

- **Armour Access.** The page says points in the store's free rewards program, 5 per $1, can be earned on a purchase that also earns cash back. Whether paying with redeemed rewards reduces the cash back is not confirmed.
- **Outlet.** The terms do not exclude the outlet section of the website. A deal for it was listed with the same 10%.
- **App.** The page mentions the store's app. The terms do not. A purchase earns only if it starts from a Rakuten link, the Rakuten app or the extension; whether an order finished in the store's app tracks is not confirmed.
- **In stores.** The store page showed an online rate only. The store did not appear in the part of Rakuten's in-store offer list that loaded on November 25, 2026; the list does not load in full, so this is not confirmed. See [how in-store cash back works](/rakuten-in-store-cash-back-how-it-works/).

## When it shows up

The page says cash back is added to the Rakuten account within one week, after the order is confirmed. Payment follows on Rakuten's four dates a year; see [when Rakuten pays](/rakuten-when-do-you-get-paid/). For another sportswear brand, see [Rakuten at Nike](/rakuten-nike-cash-back-how-it-works/).

## Who should skip it

- You have a code from the store's emails or app that saves more than the cash back.
- You are buying a gift card.
- The order ships outside the United States.
- You order on an employee or athlete account.
- You tend to return items. Rakuten's help page says returned orders do not earn.

## Quick answers

**What rate does Rakuten pay at Under Armour?**
10% on November 25, 2026, with a "was 2%" label. Rates change daily.

**Can you use a promo code and still get cash back?**
Only a code listed on Rakuten. Orders using other codes are excluded.

**Do Armour Access points and cash back stack?**
The page says both can be earned on one eligible purchase.
